# おつかい最短ルート

スーパーで献立の材料を集める順番を考え、レジまでの移動と商品の扱い方を最適化するブラウザゲームです。「AIでつくってためそ」第18回で紹介しています。

## 遊ぶ

https://ai-tsukuttetameso.github.io/tsukutte-tameso-otsukai-route/

紹介動画：https://youtu.be/H1M-Gy9upaQ （2026-11-11 19:00 JST公開予定）

## 操作

1. 小・中・大の3店舗からお店を選び、12種類の献立から買うものを決めます。
2. 商品または買い物メモをタップして、取る順番を選びます。
3. 全品を選んだら「レジへ向かう」。結果をレシートで確認します。
4. 「最短ルートで歩いてみる」で答え合わせし、同じ配置でやり直せます。

- 冷凍品はレジまでの猶予を超えると、超えた歩数の2倍を加算。
- 卵のあとに米・水・ビールを取ると20歩を加算。
- 最短の評価値は移動歩数とペナルティの合計です。
- 売り場シャッフル、端末の日付に基づく日替わり、任意の制限時間、キャラ変更があります。
- 記録・キャラの設定・写真はGitHub Pages版ではそのブラウザ内に保存します。別ブラウザや端末との自動同期、Claude Artifact版からの自動移行はありません。ブラウザのデータを消すと記録も消えます。

## 実装

HTML/CSS/JavaScriptの1ファイル構成。Google Fontsから書体を読み込みます。ビルド作業は不要です。GitHub Pagesのmainブランチ直下を配信します。

ゲーム原案・制作：ユーザーとClaudeの対話。引き継ぎ・検証・公開準備：Codex。
架空の店舗を使ったオリジナルゲームで、実際の店舗の経路案内ではありません。
